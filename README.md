## What I'm working on

**AI agents and tooling**

- [domovoi](https://github.com/getdomovoi/domovoi): a local-first harness for AI coding agents across your machines.
- [osnova](https://github.com/getdomovoi/osnova): a deterministic code map for AI coding agents. A tree-sitter symbol and call graph served over MCP and a CLI, with no embeddings, network, or telemetry.

**Cloud and self-hosting**

- [Mapwright](https://mapwright.io): self-hosted map infrastructure. Tiles, styles, geocoding, routing, and static maps behind a Mapbox-compatible API.
- A self-hosted AI platform on K3s: private LLM and RAG services with a guarded, read-only ops agent.
- [fetzycloud.online](https://fetzycloud.online): my personal site, rendered as a terminal program in Go and React.

**Game modding and servers**

- [SPT413-Phetzy-Updater](https://github.com/phetzy/SPT413-Phetzy-Updater): a Windows GUI installer and hotfix updater for an SPT 4.1.3 friends pack.
- Modded dedicated servers for friends, deployed and kept up to date with scripts.
